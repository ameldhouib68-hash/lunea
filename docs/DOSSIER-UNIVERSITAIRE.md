# Création du site e-commerce LUNÉA
Document de travail — à compléter après les tests réels.

## Présentation du projet
Dans le cadre de ma troisième année de BUT Techniques de Commercialisation, parcours Marketing Digital, E-business et Entrepreneuriat, je développe LUNÉA, une boutique fictive de veilleuses d’intérieur. Le projet associe une identité de marque à la réalisation technique d’un site marchand.

LUNÉA propose un univers doux et chaleureux, inspiré de la décoration intérieure. Son slogan est « La lumière qui change vos nuits. ». La collection prévue comprend six produits : Aube, Halo, Sora, Nacre, Éclipse et Brume, avec des prix allant de 49 à 99 euros.

## Objectifs
Le site doit présenter les produits, faciliter leur comparaison et permettre une commande de test. Il doit aussi montrer comment une identité visuelle cohérente peut accompagner le parcours client, de la découverte de la marque jusqu’au panier.

## Outils
PrestaShop gère le catalogue, les comptes, le panier et les commandes. XAMPP fournit le serveur local Apache, PHP et MariaDB. Les données sont enregistrées dans une base nommée lunea. phpMyAdmin permet de consulter cette base et SQL sert à interroger ou manipuler les données. Git conserve l’historique des changements. GitHub permet de partager les sources du projet.

## Réalisation
À ce stade, les contenus du catalogue et de la marque sont préparés. Une première base de module PrestaShop est écrite. L’installation sur le Mac, l’importation, les images, le parcours d’achat et la publication GitHub restent à vérifier. Les paragraphes suivants seront complétés avec les résultats observés.

## Fonctionnalités
Le site prévu comprend une collection filtrable, six fiches produits avec déclinaisons, une page de marque, quatre articles, un formulaire de contact et une inscription à la newsletter. Les fonctions marchandes doivent utiliser PrestaShop : panier, compte, adresse et commande de démonstration. Cette liste présente les objectifs, pas des résultats déjà validés.

## Conclusion provisoire
La préparation de LUNÉA permet de relier le positionnement d’une marque aux contenus d’un site e-commerce. La suite du travail consistera à installer la boutique, intégrer les éléments préparés et tester chaque étape du parcours client. Le bilan final sera rédigé à partir de ces tests, en indiquant les difficultés rencontrées et leurs solutions.
